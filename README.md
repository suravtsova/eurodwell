# Email-подписи EuroDwell

Фирменные подписи сотрудников EuroDwell. Всё редактируется прямо на сайте GitHub,
а готовые подписи с кнопкой «Скопировать» публикуются автоматически на сайте:

**https://suravtsova.github.io/eurodwell/**

Изменили текст или фото → через 1–2 минуты сайт обновится сам.

---

## Как вставить подпись в почту

1. Откройте https://suravtsova.github.io/eurodwell/ и найдите нужного сотрудника.
2. Нажмите **«Скопировать подпись»**.
3. Вставьте её в почту:
   - **Gmail:** ⚙ → «Все настройки» → «Общие» → «Подпись» → «Создать» → вставить (Ctrl+V / Cmd+V) →
     внизу «Сохранить изменения». Там же выберите её подписью по умолчанию для новых писем и ответов.
   - **Outlook (веб и новый Outlook):** ⚙ → «Учётные записи» → «Подписи» → «Новая подпись» → вставить → «Сохранить».
   - **Apple Mail:** откройте «Отдельную страницу» сотрудника в Safari → Cmd+A, Cmd+C →
     Mail → Настройки → «Подписи» → «+» → вставить. Снимите галочку «Всегда использовать мой шрифт по умолчанию».
   - **Сервис рассылок** (Mailchimp, Brevo, SendPulse…): «Скопировать HTML-код» → вставить в HTML-блок в конце шаблона.

> Фото и иконки в письме подгружаются с сайта подписей. Поэтому после смены фото
> подпись в почте **не нужно** вставлять заново — новое фото появится само
> (иногда через несколько часов из-за кэша Gmail). Вставлять заново нужно только при смене текста.

## Как изменить текст (имя, должность, телефон)

1. Откройте в репозитории файл **`employees.json`** и нажмите ✏️ (**Edit this file**) справа вверху.
2. Поменяйте нужные значения — только текст между кавычками:

   ```json
   {
     "id": "mary-jaszczak",
     "name": "Mary Jaszczak",
     "title": "Head of Estimation Department",
     "phone": "123-456-7890"
   }
   ```

3. Нажмите **Commit changes…** → **Commit changes**.
4. Через 1–2 минуты обновите сайт подписей. Прогресс виден на вкладке **Actions** (зелёная галочка — готово,
   красный крестик — ошибка, обычно лишняя или пропущенная запятая/кавычка).

### Добавить нового сотрудника

Добавьте ещё один блок в список `employees` — **через запятую** после предыдущего:

```json
  "employees": [
    {
      "id": "mary-jaszczak",
      "name": "Mary Jaszczak",
      "title": "Head of Estimation Department",
      "phone": "123-456-7890"
    },
    {
      "id": "john-smith",
      "name": "John Smith",
      "title": "Project Manager",
      "phone": "908-555-0101"
    }
  ]
```

`id` — латиницей, маленькими буквами, через дефис. По нему подбирается фото.
Удалить сотрудника — удалить его блок вместе с запятой.

### Дополнительные поля (необязательные)

| Поле | Что делает |
|---|---|
| `address`, `website`, `facebook`, `instagram` | Своё значение вместо общего для компании. `""` — скрыть строку |
| `addressUrl` | Своя ссылка для адреса (по умолчанию — Google Maps) |
| `tagline` | Короткий слоган рядом с логотипом |
| `variant` | `"classic"` — исходный макет вместо современного |
| `photo` | Ссылка на фото, если оно лежит в другом месте |

Общие для всех адрес, сайт и соцсети записаны в `signature.js` (раздел `DEFAULTS`).

## Как поменять или добавить фото

1. Подготовьте фото: лицо по центру, лучше квадратное, от 300×300 px, формат JPG или PNG.
2. Назовите файл как `id` сотрудника: `mary-jaszczak.jpg`, `john-smith.jpg`.
3. В репозитории откройте папку **`photos/`** → **Add file** → **Upload files** → перетащите файл → **Commit changes**.
   Если файл с таким именем уже есть, он заменится.
4. Через 1–2 минуты фото появится на сайте — уже обрезанное в круг с тонкой рамкой.

## Первоначальная настройка (один раз)

1. **Влить изменения в `main`** — сайт собирается только из основной ветки.
2. **Включить GitHub Pages:** Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. **Репозиторий должен быть публичным** (Settings → General → Danger Zone → Change visibility),
   либо нужен платный план GitHub — бесплатный Pages работает только для публичных репозиториев.
   Сам сайт подписей в любом случае открыт всем, кто знает адрес: там только то, что и так видно
   в каждом письме (имя, должность, рабочий телефон).
4. Если сайт будет по другому адресу (например, свой домен), поменяйте `config.assetsBaseUrl` в `employees.json`.

## Устройство проекта

| Файл / папка | Назначение |
|---|---|
| `employees.json` | Данные сотрудников и общие настройки |
| `photos/` | Исходные фото сотрудников (любого размера) |
| `signature.js` | Шаблоны подписи (`modern` и `classic`) |
| `generator.html` | Конструктор для разовых подписей (есть и на сайте) |
| `build.js` | Собирает сайт в папку `dist/` |
| `tools/round-photos.py` | Обрезает фото в круг |
| `tools/icons.svg.js`, `tools/render-icons.js` | Исходники иконок и их перерисовка в `assets/icons/` |
| `.github/workflows/pages.yml` | Автосборка и публикация сайта при изменениях в `main` |

Подпись свёрстана таблицами с inline-стилями, иконки — PNG, логотип — текстом, круг фото «зашит» в картинку:
только так она одинаково выглядит в Gmail, Outlook, Apple Mail и на телефонах.

Локальная сборка (необязательно): `pip install pillow && python3 tools/round-photos.py && node build.js --local`,
затем открыть `dist/index.html`.
