# Email-подпись EuroDwell

Шаблон фирменной подписи EuroDwell (фото, имя, должность, телефон, адрес, сайт, логотип, Facebook/Instagram)
с возможностью быстро сделать подпись для любого сотрудника.

Подпись свёрстана таблицами с inline-стилями, иконки — PNG, логотип — текстом.
Это единственный способ получить одинаковый вид в Gmail, Outlook, Apple Mail и на телефонах.

## Два стиля

- **modern** (по умолчанию) — современный: фото поменьше, красная акцентная полоса,
  должность капсом с разрядкой, контакты в две строки, кнопка-призыв «Get a free estimate →»,
  внизу тонкая линия, логотип и тёмные круглые иконки соцсетей.
- **classic** — исходный макет.

Стиль выбирается в конструкторе (поле «Стиль подписи») или в `employees.json` → `config.variant`;
для отдельного сотрудника можно указать своё поле `"variant"`.
Для современного стиля есть поля `cta` (текст кнопки, `""` — без кнопки), `ctaUrl` (ссылка кнопки,
по умолчанию сайт) и `tagline` (короткий слоган рядом с логотипом, по умолчанию не показывается).

## Структура

| Файл | Назначение |
|---|---|
| `generator.html` | Конструктор в браузере: ввести данные → предпросмотр → скопировать подпись |
| `signature.js` | Сам шаблон подписи (используется и конструктором, и `build.js`) |
| `employees.json` | Список сотрудников для массовой генерации |
| `build.js` | Генерирует подписи всех сотрудников в папку `dist/` |
| `assets/icons/` | Иконки (телефон, адрес, сайт, Facebook, Instagram) |
| `assets/photos/` | Круглые фото сотрудников (PNG 300×300) |
| `tools/` | Исходники иконок (SVG) и скрипт их перегенерации |

## Важно: картинки должны лежать в интернете

Почтовые клиенты показывают картинки только по публичной ссылке `https://…`.
Базовый адрес задаётся в `employees.json` → `config.assetsBaseUrl` (и в поле на странице конструктора).

По умолчанию это `https://raw.githubusercontent.com/suravtsova/eurodwell/main/` — работает,
**только если репозиторий публичный** и изменения влиты в ветку `main`.
Надёжнее положить папку `assets/` на сайт, например `https://www.eurodwell.com/email-signature/`,
и указать этот адрес.

## Способ 1. Конструктор (для одного сотрудника)

1. Откройте `generator.html` в браузере (двойным кликом).
2. Введите имя, должность, телефон.
3. Фото: загрузите любой снимок — он обрежется в круг. Нажмите «Скачать круглое фото»,
   положите файл в `assets/photos/` (или на сайт) и впишите ссылку в поле «Ссылка на фото».
4. Нажмите «Скопировать подпись» и вставьте её в настройки почты (инструкция есть на странице),
   либо «Скопировать HTML-код» для сервиса рассылок.

## Способ 2. Для всех сотрудников сразу

1. Положите фото в `assets/photos/` (квадратное или уже круглое PNG, ~300×300).
2. Добавьте сотрудника в `employees.json`:

   ```json
   {
     "id": "john-smith",
     "name": "John Smith",
     "title": "Project Manager",
     "phone": "908-555-0101",
     "photo": "assets/photos/john-smith.png"
   }
   ```

   Необязательные поля: `address`, `addressUrl`, `website`, `facebook`, `instagram`, `cta`, `ctaUrl`, `tagline`, `variant`.
   Если поле не указано — берётся общее значение компании; пустая строка `""` скрывает строку.

3. Запустите `node build.js` (Node.js 18+).
   В `dist/` появятся `<id>.html` (страница с подписью — открыть, выделить всё, скопировать)
   и `<id>.snippet.html` (чистый HTML для рассылок). `dist/index.html` — все подписи на одной странице.

   `node build.js --local` — то же, но с локальными картинками, только для предпросмотра.

## Общие данные компании

Адрес, сайт и ссылки на соцсети по умолчанию — в `signature.js` (`DEFAULTS`).
Ссылки на Facebook/Instagram сейчас заглушки — замените на настоящие страницы компании.

## Перерисовать иконки

Иконки описаны в `tools/icons.svg.js`. После правки: `node tools/render-icons.js` (нужен `playwright`).
